# Audio clips to record

Generated by `npm run clips`. Do not edit by hand.

Record in a quiet room, one MP3 per line, using exactly these file names.
Speak slowly and clearly, the way you would to a small child, because recorded clips play exactly as recorded.
Add a clip and the app uses it automatically. Until then it uses the device voice.
